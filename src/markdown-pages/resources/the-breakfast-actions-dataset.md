# The Breakfast Actions Dataset

Breakfast records 52 people preparing breakfast in 18 kitchens, with approximately 77 hours of video. Introduced at CVPR 2014, it supports activity recognition and temporal segmentation.

[Download data and annotations on Hugging Face](https://huggingface.co/datasets/Serrelab/breakfast-actions). This is the maintained download page, with archive descriptions, checksums, and video availability. The feature and segmentation archives are restored; the raw video mirror is incomplete because the original Google Drive download exceeded its quota on October 11, 2026.

For dataset specifications, activity classes, evaluation tasks, and citations, see the [Breakfast dataset overview](/breakfast-actions-dataset.html).

[HTK action-recognition code and evaluation instructions](https://github.com/hildekuehne/HTK_actionRecognition) are available on GitHub.
