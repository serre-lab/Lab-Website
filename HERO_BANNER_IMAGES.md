## Download Instructions

1. Visit any of the Unsplash links above
2. Click the download button (free download, no attribution required)
3. Save images with descriptive names:
   - `hero-research.jpg`
   - `hero-publications.jpg`
   - `hero-people.jpg`
   - `hero-resources.jpg`
   - `hero-media.jpg`
4. Place them in `/public/` directory
5. Images will be automatically used once you update the component props

## Image Requirements

- **Resolution**: At least 1920x1080px (Full HD)
- **Format**: JPG or WebP
- **File Size**: Optimize to under 500KB if possible
- **Contrast**: Should be dark enough for white text overlay (or we can adjust CSS overlay)
